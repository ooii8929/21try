# 21 Try App - Product Overview

## Product Vision

The 21 Try App is a goal tracking application based on the **21 Try Method** - the principle that it takes 21 documented attempts to master any skill or achieve any goal. The app helps users systematically track their progress through video-documented attempts with reflective notes.

## Core Value Proposition

- **Structured Progress**: Break down any goal into 21 manageable attempts
- **Video Documentation**: Capture visual evidence of each attempt for reflection
- **Reflective Learning**: Add notes and descriptions to track insights and improvements
- **Progress Visualization**: Clear visual feedback on journey to mastery

## Target Users

- Individuals learning new skills (musical instruments, sports, languages)
- People working on personal development goals (public speaking, mindfulness)
- Anyone seeking a structured approach to goal achievement with accountability

## Key User Flows

### Primary Flow: Recording an Attempt
1. User selects a goal from their dashboard
2. Views progress (X/21 attempts) and timeline of past attempts
3. Taps "Record Try" to capture video of current attempt
4. Records video using in-app camera
5. Adds title and reflective notes about the attempt
6. Saves record, which updates progress and timeline

### Secondary Flow: Goal Management
1. User creates new goal with descriptive title
2. Goal appears in dashboard with progress indicator
3. User can view detailed timeline of all attempts for each goal
4. User can edit past attempts to add or modify notes

### Tertiary Flow: Review and Reflection
1. User navigates to goal detail screen
2. Reviews timeline of all past attempts
3. Taps edit icon on any attempt to review video and notes
4. Can modify title and description for better reflection

## Success Metrics

- User completes 21 attempts for at least one goal
- User adds reflective notes to majority of attempts
- User reviews past attempts before recording new ones
- User maintains consistent recording cadence (e.g., daily/weekly)

## Design Principles

1. **Simplicity First**: Minimal UI that focuses on core actions
2. **Visual Progress**: Always show clear progress indicators
3. **Frictionless Recording**: Quick access to camera for capturing attempts
4. **Reflection-Oriented**: Encourage thoughtful notes and review
5. **Dark Theme**: Calming, focused aesthetic with green accents
